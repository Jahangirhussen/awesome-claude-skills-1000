# Workflow

DISCOVER -> SELECT -> EXECUTE -> VERIFY -> REPORT

1. Understand the goal; inspect only the relevant project files/URL.
2. Match `ROUTER.md`; open only matched parent + child files; load dependencies silently if needed.
3. If a `Merged from` source exists and the task needs depth, read that `_source/<name>/SKILL.md`.
4. Execute in `RULES.md` order; one skill if one is enough.
5. Run the smallest useful verification.
6. Report `DONE` (changes, result, open issues).
