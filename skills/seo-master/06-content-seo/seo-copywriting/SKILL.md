# SEO copywriting

ID: 06.05 | Level: child | Parent: [Content SEO](../SKILL.md)

## Purpose
SEO copywriting within the seo-master tree: Final copy plus metadata set.

## When to use
Triggers: seo copywriting, write seo article

## When NOT to use
- The topic is covered by a sibling skill: `../content-clusters`, `../content-gap`, `../content-refresh`, `../content-strategy`, `../topical-authority`.
- The task is outside this SEO category; see `ROUTER.md` at the seo-master root.

## Inputs
- Target site/URL(s) or project files, platform (CMS/framework), and goal.
- Data access as available: Google Search Console, GA4, Ahrefs/Semrush content gap, SERP analysis, content brief template, CMS.

## Core workflow
1. Start from intent and audience; answer early
2. Natural keyword use in title, H1, intro, subheads; no stuffing
3. Add proof: examples, data, quotes; clear CTA
4. Edit for clarity; add alt text, internal links, schema

## Decision rules and checks
- Hook + answer early
- Natural keyword use
- Original value, sources, no filler

## Edge cases and failure handling
- Sounds generic -> add original experience and specifics
- AI-only draft -> human review for accuracy and voice

## Validation
- Re-fetch or re-crawl changed URLs; confirm the fix is live (status, rendered HTML, canonical, schema validator, GSC URL Inspection as relevant).
- Compare with the baseline recorded before the change; check for regressions on neighbouring templates.

## Output requirements
Final copy plus metadata set. Report as a short DONE: what changed, evidence, remaining issues.

## Example
- Input/symptom: Sounds generic
- Action: add original experience and specifics
- Output: Final copy plus metadata set.
