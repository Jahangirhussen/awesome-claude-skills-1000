# Link building

ID: 05.01 | Level: child | Parent: [Off-Page SEO](../SKILL.md)

## Purpose
Link building within the seo-master tree: Outreach tracker: target, asset, status, link URL.

## When to use
Triggers: link building, outreach, resource links, broken link building

## When NOT to use
- The topic is covered by a sibling skill: `../backlinks`, `../brand-mentions`, `../digital-pr`, `../guest-posting`, `../link-audit`.
- The task is outside this SEO category; see `ROUTER.md` at the seo-master root.

## Inputs
- Target site/URL(s) or project files, platform (CMS/framework), and goal.
- Data access as available: Ahrefs, Semrush, Majestic, Google Search Console Links report, Google Alerts, outreach CRM or spreadsheet.

## Core workflow
1. Create linkable assets: original data, tools, guides, templates
2. Build target lists by relevance and audience
3. Personalized outreach with a reason to link; follow up once
4. Track placements and referral traffic

## Decision rules and checks
- Linkable assets first
- Targeted outreach, relevance over volume
- Never buy links or use PBNs

## Edge cases and failure handling
- Low reply rate -> improve asset and targeting, not volume
- Never buy links, use PBNs or link schemes

## Validation
- Re-fetch or re-crawl changed URLs; confirm the fix is live (status, rendered HTML, canonical, schema validator, GSC URL Inspection as relevant).
- Compare with the baseline recorded before the change; check for regressions on neighbouring templates.

## Output requirements
Outreach tracker: target, asset, status, link URL. Report as a short DONE: what changed, evidence, remaining issues.

## Example
- Input/symptom: Low reply rate
- Action: improve asset and targeting, not volume
- Output: Outreach tracker: target, asset, status, link URL.
