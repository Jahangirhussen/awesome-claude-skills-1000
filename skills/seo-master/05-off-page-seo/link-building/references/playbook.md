# Playbook: Link building

## How to do it
1. Create linkable assets: original data, tools, guides, templates
2. Build target lists by relevance and audience
3. Personalized outreach with a reason to link; follow up once
4. Track placements and referral traffic

## Common problems and fixes
- Low reply rate -> improve asset and targeting, not volume
- Never buy links, use PBNs or link schemes

## Output
Outreach tracker: target, asset, status, link URL.

## Tools and data sources
Ahrefs, Semrush, Majestic, Google Search Console Links report, Google Alerts, outreach CRM or spreadsheet.

## Verify
- Re-fetch or re-crawl the changed URLs and confirm the fix is live (status, rendered HTML, schema validator, GSC URL Inspection as relevant).
- Compare against the baseline you recorded before the change.
- Report what changed, the evidence, and any remaining issue in a short DONE summary.
