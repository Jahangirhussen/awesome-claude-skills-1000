# Playbook: Digital PR

## How to do it
1. Find a newsworthy angle: study, survey, trend, expert commentary
2. Build a media list by beat; pitch with data and visuals
3. Prepare assets: press page, charts, quotes
4. Measure coverage, links, brand search

## Common problems and fixes
- Pitches ignored -> sharpen angle and relevance
- Coverage without links -> request attribution politely

## Output
Campaign brief and coverage report.

## Tools and data sources
Ahrefs, Semrush, Majestic, Google Search Console Links report, Google Alerts, outreach CRM or spreadsheet.
