# Digital PR

ID: 05.03 | Level: child | Parent: [Off-Page SEO](../SKILL.md)

## Purpose
Digital PR within the seo-master tree: Campaign brief and coverage report.

## When to use
Triggers: digital pr, press, data study

## When NOT to use
- The topic is covered by a sibling skill: `../backlinks`, `../brand-mentions`, `../guest-posting`, `../link-audit`, `../link-building`.
- The task is outside this SEO category; see `ROUTER.md` at the seo-master root.

## Inputs
- Target site/URL(s) or project files, platform (CMS/framework), and goal.
- Data access as available: Ahrefs, Semrush, Majestic, Google Search Console Links report, Google Alerts, outreach CRM or spreadsheet.

## Core workflow
1. Find a newsworthy angle: study, survey, trend, expert commentary
2. Build a media list by beat; pitch with data and visuals
3. Prepare assets: press page, charts, quotes
4. Measure coverage, links, brand search

## Decision rules and checks
- Original data/story angle
- Journalist targeting
- Track coverage + links

## Edge cases and failure handling
- Pitches ignored -> sharpen angle and relevance
- Coverage without links -> request attribution politely

## Validation
- Re-fetch or re-crawl changed URLs; confirm the fix is live (status, rendered HTML, canonical, schema validator, GSC URL Inspection as relevant).
- Compare with the baseline recorded before the change; check for regressions on neighbouring templates.

## Output requirements
Campaign brief and coverage report. Report as a short DONE: what changed, evidence, remaining issues.

## Example
- Input/symptom: Pitches ignored
- Action: sharpen angle and relevance
- Output: Campaign brief and coverage report.
