# Playbook: Comparison and alternative pages

## How to do it
1. Create 'X vs Y' and 'alternatives to X' with honest tables
2. Include pricing, features, who each is best for; update dates
3. Avoid false claims; cite sources
4. Strong CTA and trial path

## Common problems and fixes
- Biased copy loses trust -> be fair and specific
- Outdated data -> schedule quarterly reviews

## Output
Comparison page template and competitor list.

## Tools and data sources
Ahrefs/Semrush competitor tools, GSC, analytics funnels, CMS, screenshot tools, schema validator.

## Verify
- Re-fetch or re-crawl the changed URLs and confirm the fix is live (status, rendered HTML, schema validator, GSC URL Inspection as relevant).
- Compare against the baseline you recorded before the change.
- Report what changed, the evidence, and any remaining issue in a short DONE summary.
