# Comparison and alternative pages

ID: 12.03 | Level: child | Parent: [SaaS SEO](../SKILL.md)

## Purpose
Comparison and alternative pages within the seo-master tree: Comparison page template and competitor list.

## When to use
Triggers: vs, alternative, comparison, alternatives to

## When NOT to use
- The topic is covered by a sibling skill: `../feature-pages`, `../integration-pages`, `../landing-pages`, `../programmatic-saas`.
- The task is outside this SEO category; see `ROUTER.md` at the seo-master root.

## Inputs
- Target site/URL(s) or project files, platform (CMS/framework), and goal.
- Data access as available: Ahrefs/Semrush competitor tools, GSC, analytics funnels, CMS, screenshot tools, schema validator.

## Core workflow
1. Create 'X vs Y' and 'alternatives to X' with honest tables
2. Include pricing, features, who each is best for; update dates
3. Avoid false claims; cite sources
4. Strong CTA and trial path

## Decision rules and checks
- 'X vs Y' and 'alternatives to X'
- Honest tables, updated dates
- Strong CTA

## Edge cases and failure handling
- Biased copy loses trust -> be fair and specific
- Outdated data -> schedule quarterly reviews

## Validation
- Re-fetch or re-crawl changed URLs; confirm the fix is live (status, rendered HTML, canonical, schema validator, GSC URL Inspection as relevant).
- Compare with the baseline recorded before the change; check for regressions on neighbouring templates.

## Output requirements
Comparison page template and competitor list. Report as a short DONE: what changed, evidence, remaining issues.

## Example
- Input/symptom: Biased copy loses trust
- Action: be fair and specific
- Output: Comparison page template and competitor list.
