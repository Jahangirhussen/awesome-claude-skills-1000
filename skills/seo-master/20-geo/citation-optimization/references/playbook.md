# Playbook: Citation optimization

## How to do it
1. Publish unique facts others will cite
2. Make them easy to quote (short, specific, dated)
3. Link out to primary sources

## Common problems and fixes
- Claims without sources -> add references

## Output
Citable-statements list.

## Tools and data sources
Prompt tracking sheet, AI engines, citation checks, schema validator, brand mention monitoring.
