# Ecom Product Hero — Design System

## Core Strategy

Answer 4 questions within 3 seconds:
1. What is it?
2. Why choose it?
3. Is it trustworthy?
4. Where's it from?

## Visual Hierarchy

Product image: centered, dominant
Supporting layers build atmosphere around it.

## Key Visual Layers

Stack these 5 atmospheric elements:
1. Contextual landscape background (product origin)
2. Cool-toned overlay gradient
3. Warm product glow
4. Subtle light rays for depth
5. Ground mist anchoring the item

"Cool blue-grey overlays on nature photography create the premium water association (clarity, purity, science)."

## Typography

| Role | Weight | Color |
|------|--------|-------|
| Numbers/specs | 200 (thin) | White |
| Chinese labels | 600-700 (bold) | White |
| Gold accent keyword | 500 | #d4a853 |
| Data matrix labels | 400 | #d4a853 |

Rule: gold is SCARCE — 1 keyword max in headline, data labels only.

## Data Matrix

5-column spec table:
- Semi-transparent dark background
- Hairline dividers between columns
- Readable at 3+ meter viewing distance

## Overlay Temperature Guide

| Product type | Overlay color | Effect |
|---|---|---|
| Water/beverage | Cool blue-grey | Purity, clarity |
| Food/snack | Warm amber | Appetite, warmth |
| Health/supplement | Deep green | Nature, vitality |
| Tech product | Dark navy | Precision, trust |

## Adapting Across Categories

Keep constant:
- 5-layer atmospheric stack
- Gold accent sparingly
- Minimal text
- Centered product

Adjust per category:
- Background imagery (match origin story)
- Overlay temperature
- Metric positioning
