# Rules

- User describes WHAT; pick the domain/skill yourself; never ask which skill; never announce routing.
- Load only matched domain `SKILL.md`, then the one skill needed, then references only if required. Never read the whole library.
- Prefer an installed specific skill over a generic one. Imported skills are read-in-place (no slash command).
- No duplication: link to the canonical skill via `DEPENDENCIES.md`.
- Inspect first, change only what is needed, verify, short `DONE` report.
- Respect source licenses (`_licenses/`).
