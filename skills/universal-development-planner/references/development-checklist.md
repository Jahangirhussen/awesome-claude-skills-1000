# Pre-development gate

[ ] PRD complete  [ ] Features defined  [ ] Requirements defined  [ ] User roles defined
[ ] User flows defined  [ ] Architecture defined  [ ] Tech stack defined  [ ] Database designed
[ ] API planned  [ ] Authentication planned  [ ] Authorization (RBAC) planned  [ ] Security planned
[ ] UI/UX planned  [ ] Routes planned  [ ] Components planned  [ ] Integrations identified
[ ] Testing strategy defined  [ ] Deployment strategy defined  [ ] Environment variables defined
[ ] Traceability table filled  [ ] Consistency audit done (no contradictions)

# Final verification (before declaring done)
[ ] Every planned feature and requirement implemented  [ ] Every route and API works
[ ] DB relations correct, migrations run clean  [ ] Auth and permissions verified (allowed and denied)
[ ] UI matches spec incl. empty/loading/error states  [ ] Validation and error handling work
[ ] Security controls verified  [ ] Tests pass (unit, integration, E2E)  [ ] Production build works
[ ] Docs, CHANGELOG, TODO updated
