## What is this

[Claude Code Agent Skills](https://docs.claude.com/en/docs/claude-code/skills) let Claude autonomously load specialized instructions, scripts, and references when a task matches. This repo bundles **1016 skills** across software development, design, marketing, research, and more into one browsable collection.

## Install

Copy any skill folder into your Claude Code global skills directory:

```bash
cp -r skill-name ~/.claude/skills/
```

Or clone the whole thing:

```bash
git clone https://github.com/Jahangirhussen/awesome-claude-skills-1000.git
cp -r awesome-claude-skills-1000/skills/* ~/.claude/skills/
```
